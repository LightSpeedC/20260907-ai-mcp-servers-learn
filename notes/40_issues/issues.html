実測（2 件）

未i261009-01 Codex・Antigravity にもツールを呼ばせて確かめる

いま全章を実測しているのは Claude Code だけです。Codex と Antigravity は、登録コマンドの書式と、接続時に名乗る MCP の版（protocolVersion）までしか確かめていません。

実際にツールを呼ばせるには、ホーム配下の設定（~/.codex/config.toml 等）への書き込みが要ります。プロジェクト外への書き込みになるので、着手の前に許可を取る。

状態やること
未書き込み先と目的を示して許可を取る
未Codex にメモサーバーを登録し、memo_add・memo_search を呼ばせる
未Antigravity でも同じことを行う
未結果を 04 章と計画書に反映する
未i261009-02 テストランナーが他プロジェクトの .js を実行した件の影響を確かめる

ランチャーが node --test に対象を渡し損ね、カレント配下（プロジェクトの外を含む）を探して、他プロジェクトのファイルを実行しました。プロセスの残りと待ち受けは無いことを確かめています。書き込みは行っていません。

実行されたファイルが何かを書き換えていないかは、まだ確かめていません。確かめるには他プロジェクトを読むことになるので、対象と目的を示して許可を取ってから行う。

状態やること
未調べるかどうかを決める
済ランチャーを直し、対象を絶対パスの配列で渡す
済共通ルールに「対象を渡すコマンドは、渡ったことを確かめてから実行する」を加える
